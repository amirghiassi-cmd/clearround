FAQ

Quick answers.

Which app should I choose?

Choose ClearRound if you run your own round and want simple customer, schedule and money tracking. Choose ClearRound Pro if you manage multiple rounds and want to share jobs with workers through worker sheets.

Can ClearRound Pro handle more than one round?

Yes. ClearRound Pro supports multiple rounds, so you can organise customers and due jobs by round and switch between them as needed.

What is a worker sheet?

It is a shareable mobile page for jobs you assign to a worker. You choose which jobs to include, can add instructions, control whether prices or customer contact details are shown, and set when the link expires. Workers can report a job as done or tell you when they need to skip, cancel or could not complete it.

Does a worker need to install an app?

The worker sheet opens from a link in a mobile browser, so the worker can view the assigned jobs without installing ClearRound Pro.

Is ClearRound Pro really £8 a month?

Yes. ClearRound Pro has one straightforward price: £8 per month. No tiers and no surprise add-ons. We intend to keep the price at £8 a month.

Does ClearRound work on iPhone and iPad?

ClearRound is designed for iPhone and iPad. Use the phone for day-to-day work and a larger screen when you want more room for admin.
